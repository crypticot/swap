How conversions work
CSV — types are detected automatically; the delimiter can be changed in Settings.
XLSX — only the first sheet is read on the way in, and output workbooks get one sheet.
JSON — an array of objects becomes rows directly, a single object becomes one row, and nested fields flatten into parent.child columns. Converting JSON to JSON just reformats the original structure instead, without flattening.
